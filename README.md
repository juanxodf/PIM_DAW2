📘 **Asignatura:** Proyecto Intermodular  

## 📖 Descripción de la asignatura
En el **Proyecto Intermodular** ponemos en práctica todos los conocimientos adquiridos durante el ciclo de **Desarrollo de Aplicaciones Web**, integrando contenidos de las distintas asignaturas en un único proyecto global.  

Se trata de una asignatura clave porque simula un entorno real de desarrollo, donde hay que planificar, diseñar, implementar y documentar una aplicación web completa.  

### 🔧 Tecnologías y áreas implicadas
- **Frontend**: HTML5, CSS3, JavaScript, frameworks (Bootstrap, Tailwind, etc.).  
- **Backend**: PHP, Laravel u otros frameworks trabajados en clase.  
- **Bases de datos**: MySQL / MariaDB.  
- **Diseño de interfaces**: wireframes, mockups y guías de estilo.  
- **Metodologías**: trabajo en equipo, control de versiones con Git/GitHub, metodologías ágiles (Scrum, Kanban).  
- **Documentación**: memoria técnica, manual de usuario, presentación del proyecto.  


## 🎯 Objetivos
- Integrar los conocimientos de todas las asignaturas del ciclo.  
- Desarrollar un proyecto completo, desde la idea inicial hasta la aplicación funcional.  
- Fomentar el **trabajo en equipo** y el uso de metodologías ágiles.  
- Aprender a documentar y presentar un proyecto de forma profesional.
